# Model Painting

Notes and guides on painting plastic scale models.

- [Painting Plastic Models: A User Guide](docs/painting-guide.md) — preparation, primer,
  base colours, metallics, decals, washes, weathering, rust and verdigris effects,
  products, troubleshooting and safety.
- [Painting by Material](docs/painting-by-material.md) — preparation, primer and paint for
  polystyrene kits, PLA and PETG 3D prints, and Lexan (polycarbonate) RC bodies.
- [Working with AK Interactive Acrylics, Enamels and Pigments](docs/ak-interactive-workflow.md)
  — layering order, thinners, drying times and recipes for an AK-based kit.
- [Sealing Finished Work: Clear Top Coats](docs/clear-coats.md) — choosing and applying gloss,
  satin and matte varnishes, sealing weathering and pigments, and tough clears for 3D prints.
